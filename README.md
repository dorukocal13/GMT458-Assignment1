# GMT458 - WebGIS Personal Web Page

## Project Overview
This project is a personal WebGIS portfolio developed for the GMT458 course. It showcases my academic background in Geomatics Engineering, technical competencies, and interactive mapping skills. The website features a responsive, modern emerald-green design and includes an interactive map section utilizing both Leaflet and OpenLayers libraries.

## Technical Details & Features
* **Core Technologies:** HTML5, CSS3, JavaScript.
* **Interactive Maps:** 
  * Integrates **Leaflet** for single-point visualization (Hacettepe University).
  * Integrates **OpenLayers** for displaying multiple points (Erasmus Exchange program locations: Warsaw University of Technology and Politecnico di Milano).
* **Dynamic Language Switcher:** A custom JavaScript implementation allowing seamless toggling between English (Default) and Turkish.
* **Session Persistence:** Utilizes JavaScript's `sessionStorage` to maintain the user's selected language preference while navigating between different pages within the same active session.
